SUPER APP API SPECIFICATION DRAFT

This document outlines the foundational REST API required to support the Flutter Super App architecture. It covers secure, role-based authentication and the "Mini App Registry" responsible for delivering Over-The-Air (OTA) updates.

Base URL: https://api.vcyoursuperapp.com/v1

==================================================
1. Authentication & Authorization (Laravel Setup)
==================================================
* Laravel Recommendation: Use Laravel Sanctum for issuing API Mobile Tokens.
* RBAC Recommendation: Use the `spatie/laravel-permission` package.

1.1 Login

POST /auth/login
Authenticates a user and returns tokens and Spatie RBAC permissions.

Request Body:
{
  "email": "user@example.com",
  "password": "Password123!",
  "deviceToken": "fcm_token_xyz" 
}

Response (200 OK):
{
  "status": "success",
  "data": {
    "user": {
      "id": "usr_987654321",
      "name": "Jane Developer",
      "email": "user@example.com",
      "roles": ["employee", "merchant_manager"],
      "permissions": [
        "view_dashboard",
        "manage_inventory",
        "access_merchant_miniapp"
      ]
    },
    "tokens": {
      "accessToken": "1|LaravelSanctumTokenString...",
      "refreshToken": "d7a8f9e0-3b4c-4d5e-8f9a...",
      "expiresIn": 900
    }
  }
}

--------------------------------------------------

1.2 Refresh Token

POST /auth/refresh
Trades the valid refreshToken for a brand new token pair.

Request: {"refreshToken": "d7a8f9e0..."}
Response: new accessToken and refreshToken.

--------------------------------------------------

1.3 Get Current Profile

GET /auth/me
Headers: Authorization: Bearer {accessToken}

2. Mini-App Registry
==================================================
This API tells the Super App which React Vite apps are available.

2.1 Get Available Mini-Apps 

GET /miniapps
Headers: Authorization: Bearer {accessToken}

* Laravel Recommendation: This controller should check the Auth::user()->roles and only return rows from your `MiniApps` eloquent model that match the user's role.

Response (200 OK):
{
  "status": "success",
  "data": {
    "miniApps": [
      {
        "id": "food_delivery_app",
        "name": "Food Delivery",
        "version": "2.1.4",
        "description": "Order food from local restaurants.",
        "iconUrl": "https://cdn.vcyourcompany.com/icons/food.png",
        "downloadUrl": "https://cdn.vcyourcompany.com/bundles/food_delivery_v2.1.4.zip",
        "bundleHash": "a8f5f167f44f4964e6c998dee827110c"
      }
    ]
  }
}

--------------------------------------------------

2.2 Direct Bundle Download (Laravel Storage)

GET /bundles/{filename}.zip

* Laravel Recommendation: Don't serve the ZIP directly from the PHP process if possible. Upload the React Vite `.zip` builds to AWS S3 using Laravel's `Storage::disk('s3')` and return the temporary/public URL in the `downloadUrl` field above.

==================================================
3. React Vite Note (For your Frontend Team)
==================================================
Because your Mini-Apps are built in React with Vite and will be downloaded and executed from the phone's LOCAL File System (`file:///data/user/0/.../index.html`), your React team must follow these rules:

1. Routing: They CANNOT use `BrowserRouter`. They MUST use `HashRouter` or `MemoryRouter` from 'react-router-dom'. A local file system has no web server to handle standard URL path fallbacks.
2. Vite Base Path: In `vite.config.ts`, they must set `base: './'` so that asset imports (JS/CSS files) use relative paths instead of absolute domain paths.
3. Super App Bridge: Since the React app works inside a Flutter WebView, the React team must communicate using the global bridge: `window.SuperAppBridge.postMessage(...)` for native features.

4. Order Management (DEMO)
==================================================
This API handles order submission from mini-apps.

4.1 Submit Order

POST /orders
Authentication: None (Public Demo)

Request Body:
{
  "items": [
    {
      "product_id": 1,
      "quantity": 2,
      "price": 18.99
    }
  ],
  "total_amount": 37.98,
  "shipping_address": "123 Demo St, Testing City",
  "payment_method": "cash_on_delivery"
}

Response (201 Created):
{
  "status": "success",
  "message": "Order submitted successfully",
  "data": {
    "order_id": 15,
    "total_amount": "37.98",
    "item_count": 1
  }
}
